# برنامهٔ مطالعه (PHP + SQLite)

مدیریت دروس، تقسیم صفحات در بازهٔ ۴ ماهه، ثبت ساعت مطالعه و آمار روزانه/هفتگی/ماهانه/سالانه.
تاریخ شمسی، ارقام فارسی، فونت وزیر، پنل مدیریت با منوی سبک وردپرس.

## نصب
1. پوشه را روی هاست (PHP ۸٫۰ یا بالاتر با `pdo_sqlite`) بارگذاری کنید.
2. به پوشهٔ `data/` دسترسی نوشتن بدهید.
3. آدرس سایت را باز کنید؛ صفحهٔ «ایجاد اولین مدیر» نمایش داده می‌شود.
   بعد از ساخت اولین مدیر، ثبت‌نام عمومی کاملاً غیرفعال است و مدیر جدید فقط از «کاربران ‹ افزودن مدیر» ساخته می‌شود.

اجرای محلی برای تست:

    php -S 127.0.0.1:8080 -t .

## فونت وزیر
برای کار بدون اینترنت، این فایل‌ها را در `assets/fonts/` بگذارید:
`Vazir-Regular.woff2` و `Vazir-Bold.woff2` (از مخزن rastikerdar/vazir-font).
اگر نباشند، فونت از CDN (jsDelivr) بارگذاری می‌شود.

## امنیت
- نام فایل دیتابیس تصادفی است (`data/dbname.php` آن را نگه می‌دارد) و `data/` و `inc/` با `.htaccess` بسته‌اند.
- روی **nginx** حتماً این را اضافه کنید (`.htaccess` اثری ندارد):

      location ~ ^/(data|inc)/ { deny all; }

- بهتر است پوشهٔ داده را بیرون از public_html بگذارید: متغیر محیطی `DARSYAR_DATA_DIR` را به مسیر آن پوشه (قابل نوشتن) تنظیم کنید.
- گذرواژه‌ها با `password_hash`، فرم‌ها با توکن CSRF، و ورود با محدودیت ۵ تلاش ناموفق در ۱۵ دقیقه محافظت می‌شوند.
- روی HTTPS بودن سایت را فعال کنید؛ کوکی نشست در این حالت خودکار `Secure` می‌شود.

## نحوهٔ محاسبهٔ برنامه
- هر درس: «تعداد صفحات»، «صفحهٔ شروع»، بازهٔ تاریخ (پیش‌فرض ۴ ماه شمسی) و هدف روزانهٔ زمان (دقیقه).
- صفحات به‌طور مساوی بین روزهای مطالعهٔ بازه تقسیم می‌شود (روزهای استراحت از «تنظیمات ‹ برنامه‌ریزی»).
- عدد «امروز» در پیشخوان از صفحات باقی‌مانده ÷ روزهای باقی‌مانده محاسبه می‌شود؛ اگر عقب بیفتید خودکار بیشتر می‌شود.
- هفته از شنبه شروع می‌شود. تاریخ‌ها در دیتابیس میلادی ذخیره و در نمایش شمسی هستند.
